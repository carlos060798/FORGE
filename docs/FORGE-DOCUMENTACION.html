1. Qué es

FORGE convierte una tarea en código probado sin que el modelo decida cuándo «está listo»: el control lo lleva un enrutador determinista que mira el código de salida de las pruebas ejecutadas en un contenedor aislado. Una persona aprueba el resultado al final.

Principios que se comprueban en código
  • Las pruebas las escribe un rol distinto del que escribe el código.
  • El código generado solo se ejecuta en Docker, sin red.
  • Hay tope de gasto, puntos de guardado y diario de respuestas: el ciclo se reanuda y se audita.
  • La aprobación humana es el último paso; nada se publica en plataformas externas sin ella.

5. Instalar y ejecutar

El paquete está empaquetado en dist/forja-mvp-5.0.0.tgz (generado con npm pack). No está publicado en npm: el instalable local es la vía de prueba.

# 1. Instalar desde el paquete local, en cualquier carpeta
npm install -g ./dist/forja-mvp-5.0.0.tgz

# 2. Comprobar el entorno (Node, Docker, proveedores)
forge doctor

# 3. Iniciar un proyecto y ejecutar el ciclo con tareas
forge init
forge run --motor ciclo --tasks tareas.json --cwd mi-proyecto

# Sin instalar globalmente
npx --package ./dist/forja-mvp-5.0.0.tgz forge doctor
# Pruebas en cinco proyectos independientes
node scripts/pruebas-independientes.mjs --modelo humo        # sin gasto
$env:ANTHROPIC_API_KEY='...'                                  # solo en la sesión
node scripts/pruebas-independientes.mjs --modelo real --proyectos js-nuevo --tope 0.15
